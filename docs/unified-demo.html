About capacity and these records

Memory reporting is an approximate JavaScript heap budget when the browser exposes it. It does not measure free system RAM or all worker and WASM memory. Disk space is this origin’s estimated storage quota, shared with other pages on the origin.

Generation uses the official SDS bindings and binary schemas. Queries stream every result allowed by your SQL. The preview shows the first 100 rows and shortens long text; the counter reports all received rows. Add LIMIT / OFFSET to inspect another range.
