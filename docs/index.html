Design Decisions

  • Zero Deserialization — Data stays in FlatBuffer format, extracted on-demand
  • Source Routing — Same schema, multiple sources; query by _source field
  • Persistent streams — Original records with derived indexes and compaction
  • SQLite VTable — Full SQL without data copying

One engine across hosts

  • One WASM artifact — The same engine in browsers and servers
  • Binary schemas — Register BFBS from an external compiler
  • SDS QRP — Typed FlatBuffer requests and result pages
  • SDS GJN — Standard binary geometry

Trade-offs

  • Raw records — Return the original FlatBuffer bytes
  • SQL projections — Return typed values in FlatBuffer pages
  • Binary boundary — Convert text with a separate tool
  • Persistent — FlatBuffer streams with derived SQLite indexes

One FlatBuffer API

Register a binary schema, ingest records, and stream typed query results. Convert JSON or GeoJSON separately with flatc-wasm.

import { FlatSQL } from 'flatsql';

const db = await FlatSQL.open({ root: 'customer-data' });
await db.registerSchema({ name: 'GJN', fileIdentifier: '$GJN', bfbs });
await db.ingest('GJN', sizePrefixedRecords);

// qrpRequest is an SDS QRP FlatBuffer containing SQL and typed parameters.
for await (const page of db.query(qrpRequest)) {
    consumeFlatBufferBytes(page);
}
await db.close();
